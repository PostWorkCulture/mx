# MX

3D desert racing in the browser: pick a monster truck or a dirt bike, then Roam the dunes freely or Race point-to-point sprints.

![Desert sprint preview](desert/desert_sprint_preview.jpg)

**Play:** open `index.html` from a local web server (`npx serve`), or the GitHub Pages site once published.

Controls: W/↑ throttle · S/↓ brake · A/D steer (on the bike you lean) · R reset to course · C camera · Esc pause · gamepad supported.
On the bike, W lifts the nose in the air and S drops it – land on both wheels or you'll go down.

Routes: Dune Sea Dash, Canyon Run, Mesa Sprint (~3.3 km each).

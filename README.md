# MX

3D desert racing in the browser: monster trucks, dune jumps and point-to-point sprint races.

![Desert sprint preview](desert/desert_sprint_preview.jpg)

**Play:** open `index.html` from a local web server (`npx serve`), or the GitHub Pages site once published.

Controls: W/↑ throttle · S/↓ brake · A/D steer · R reset to course · C camera · Esc menu · gamepad supported.

Routes: Dune Sea Dash, Canyon Run, Mesa Sprint (~3.3 km each).
